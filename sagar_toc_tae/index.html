RNN State Traversal Tracker

Train a small recurrent network on a finite automaton, then watch its continuous hidden state walk through the automaton’s discrete states.

How the projection works

At every input symbol the RNN updates a hidden vector ht = tanh(Wxhxt + Whhht−1 + b). A DFA instead jumps between a few named states. To compare them, each ht is projected onto a DFA state class in two independent ways:

  • Readout: the network’s own softmax layer picks the most likely DFA state.
  • Centroid: the nearest class mean of hidden vectors collected for each true DFA state.

If the projected path equals the DFA path at every step, the RNN has learned the automaton. Inputs with symbols outside the alphabet are rejected before the RNN runs.
